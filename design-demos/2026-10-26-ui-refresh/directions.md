# Six Candidates

All candidates use the same clipboard examples and preserve text-only replay.

## A. Control Room - Selected For Full Proposal
Real reference: inspected TailD overview screenshot and installed LLM Coordinator
CSS, recorded in brand-spec.md. Borrow neutral charcoal, a narrow icon rail and
quiet semantic colors. Desktop: dense history table plus an adjacent selected-item
inspector. Android: history-first list with separate Health and Settings tabs.
The selected text and delivery outcome are the main material. Boldness is spent
on making the inspector useful, not decorating the background. Form comes from
the repeated task of finding a copy and understanding its outcome.

## B. Clear Desk - Selected For Full Proposal
Designer lens: Dieter Rams' task-led hierarchy, not a copy of a historical object.
White workspace, dark ink, cyan selection and restrained semantic colors.
Desktop: document-like history list, selected content expanded within the flow,
horizontal navigation instead of an icon rail. Android: spacious stacked text
entries and a compact native bottom navigation. Boldness is spent on readable
clipboard text. Form comes from reading and reusing text rather than watching logs.

## C. Quick Switch - Selected For Full Proposal
Real structural reference: the inspected Command Palette style specimen
(assets/style-specimens/app/08-command-palette.jpg), adapted to Windows rather
than copied as a Mac shortcut palette. Desktop: compact search-first window with
list/preview split and fixed selection actions. Android: compact chronological
list and selected-entry action sheet. Neutral dark surfaces, cyan brand cue,
amber pending state. Form comes from retrieving one recent entry quickly.

## D. Service Console - Alternate
Designer lens: Susan Kare's functional icon clarity. Desktop full-width event
ledger and a persistent bottom health strip; Android service-first with history
below. Same artwork; visible capture/transport distinctions. Less suitable as the
default because diagnosis would dominate everyday copying.

## E. Native Notebook - Alternate
Roulette: sampled second 09; App style 10 Native Polish. Viewed its supplied
specimen. Borrow list rhythm, restrained separators and in-place expansion, not
iPhone chrome or floating task cards. Desktop light three-column groups and
Android time-grouped entries. Less distinct from Clear Desk, so kept as alternate.

## F. Signal Index - Alternate
Roulette: sampled second 09; East style 10 Hattori Playful Offset. Viewed its
supplied specimen. Translate its single focal offset into a cyan selected-entry
marker and a compact two-column history index; discard poster stripes/giant type
because they impede utility use. Deliberately lower specimen fidelity (~35%):
functional requirements outweigh the poster treatment. Kept as alternate because
the graphic emphasis is weaker than the three task-led proposals.

## Shared Visual Contract
No landing page, marketing statistics, decorative charts or fabricated live data.
Directions differ in hierarchy and navigation, not only color. A prioritizes
diagnostic context; B prioritizes legibility; C prioritizes speed and compactness.
All previews run entirely locally with simulated actions; Copy/Resend do not write
to the host clipboard or contact the production server.
