# ClipCascade 3.2.0.34

Android and Windows client interface refresh. The server remains 3.2.0.33;
this release does not contain or require a replacement server JAR.

## Changes

- Control Room layout inspired by TailD and LLM Coordinator: charcoal surfaces,
  cyan controls and the existing ClipCascade artwork.
- History-first workspace, local search and All/Text/Needs attention filters,
  full retained text and event details, and separate Copy and Resend actions.
- Sent remains unconfirmed; Delivered/Applied retain their existing application
  acknowledgement meaning. Non-text events cannot trigger text replay.
- Connection, clipboard capture, service and encryption health remain separate.
  Existing settings, enrollment, recovery and notification policies are retained.
- Windows title bars and resize borders follow the dark app palette. Native
  window controls and the original white tray icon are preserved. Closing the
  activity window leaves monitoring running. Health/settings scroll at small sizes.
- Windows app dialogs retain a visible OK button and use themed scrollbars.
- Android bottom controls respect system navigation/cutout insets, including
  Android 15 edge-to-edge layouts.

## Packages

- `ClipCascade-Android-3.2.0.34.apk`: versionCode 3020034, existing package/signing
  identity; install in place through your normal Android update workflow.
- `ClipCascade-Windows-3.2.0.34.exe`: embedded file/product version 3.2.0.34.
- `SHA256SUMS`: digests of both downloadable client packages.

Native UI screenshots use harmless fixture data, not production clipboard history.
Debug-only Android preview entry points are disabled in the release build.
